# 💰 Nikel - Controle Financeiro

O **Nikel** é uma aplicação web simples e funcional de controle financeiro desenvolvida como projeto do **Codaí**. O objetivo da aplicação é permitir o cadastro, visualização e gerenciamento de entradas e saídas de saldo de forma prática e intuitiva.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica das páginas.
- **CSS3**: Estilização e layout responsivo.
- **JavaScript (ES6+)**: Lógica da aplicação, manipulação do DOM e persistência local.

---

## 📌 Funcionalidades

- **Autenticação**:
  - Cadastro de novos usuários.
  - Login e autenticação básica.
  - Persistência de sessão (opção para manter-se logado).
- **Gerenciamento Financeiro**:
  - Visualização do saldo total.
  - Adição de lançamentos de entrada (receitas) e saída (despesas).
  - Listagem das movimentações financeiras recentes.
  - Filtro e navegação entre lançamentos.
